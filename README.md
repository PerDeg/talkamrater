# Talkamrater

Ett mattespel för att öva talkamrater (6 + 2 = 8, 4 + 4 = 8 …) för talen 1–20. Gjort för Edwin, 8 år.

## Spela

Öppna `index.html` i en webbläsare. Allt ligger i en enda fil, så det behövs ingen server eller installation.

För att spela på webben: aktivera **GitHub Pages** under *Settings → Pages*, välj *Deploy from a branch* och den gren som har `index.html` (mappen `/ (root)`).

## Spelsätt

- **Hitta kamraten** – "6 + ? = 8". Pärlor visar hur många som finns och hur många som fattas. 10 frågor per runda.
- **Bubbelpoppen** – poppa två bubblor som tillsammans blir rätt tal.
- **Blandat 1–10 / 1–20** – olika tal i varje fråga.

## Belöningar

- Hejarop (Yeay!, Wohoo!, Grymt! …), konfetti, ljud och en röst som hejar (kan stängas av).
- Svit-bonus vid 3, 5, 7 och 10 rätt i rad.
- 1–3 stjärnor per runda, sparas per tal.
- Ett klistermärke efter varje runda – samla alla 30 i klistermärkesboken.
- Nya titlar när stjärnorna växer: Talspanare → Talkompis → Plusproffs → Mattehjälte → Talkamratmästare → Mattelegend.

Vid fel svar förklarar spelet varför (t.ex. "6 + 3 = 9. Det ska bli 8, så det blev för många") och efter två försök numreras de tomma pärlorna som hjälp.

Framsteg sparas i webbläsaren (localStorage).
